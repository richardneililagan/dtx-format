# Specification

Not yet written. The format is currently described only by implementations:

- `dtxmania-poly`'s `CDTX.cs` — 7,148 lines of accumulated DTX, BMS, GDA and
  G2D behaviour, pinned by the golden corpus
- ghostnote's `packages/crawler/parse/dtx-parser.ts`
- the [DTXMania Wiki](https://osdn.net/projects/dtxmania/wiki/DTX%20data%20format),
  which is the closest thing to a published description and is incomplete

Writing this down is not scheduled yet. When it is, the corpus is the source of
truth to write it *against* — a spec that disagrees with the fixtures is wrong,
because the fixtures describe what real charts actually do and what players
already hear.
